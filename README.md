<h1 align="center">PomodoroWeb</h1>

## Stack Techno

Le projet doit être reproductible. Pour cela, il sera dockerisé.

### Base de données

- PostgreSQL (Base de Données)
- Flyway (Migration de la base de données)
- pgAdmin (Administrer la Base de Données)

### BackEnd

- Node (Runtime)
- Express (Routing)
- bcrypt (Hachage)
- JWT (token de session)
- *NC* (Système de mailing automatique)

### Frontend

- React (SPA)
- React Router (Routing)
