<h1 align="center">PomodoroWeb</h1>

## Description du projet

Le Pomodoro doit permettre :

- De choisir le temps d'une séssion.
- De choisir le nombre de session avant une pause
- De pouvoir s'inscrire de manière protégé
- De pouvoir se connecter à son compte de manière protégé
- De créer une liste de tâche à effectué
- Donner le temps a faire pour une tâche
- Lié le temps d'une tâche avec le pomodoro (ex: tâche 1 = 2 cycle, se supprime après 2 cycle de pomodoro)
- A la fin d'un cycle, le pomodoro doit sonner (choix entre plusieurs sonnerie)
- Le compte permet la persistance de toutes les données sauvegardé
